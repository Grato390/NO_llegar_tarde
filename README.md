# Mi Horario y Tareas

Una aplicación web para gestionar horarios de clases y tareas académicas, diseñada para funcionar directamente en el navegador sin necesidad de instalaciones adicionales.

## Características

- 📅 Calendario semanal interactivo para gestionar horarios de clases
- ✅ Sistema de gestión de tareas con fechas de entrega
- 🔔 Recordatorios de tareas próximas
- 📱 Diseño responsive para todos los dispositivos
- 💾 Almacenamiento local para persistencia de datos
- 🎨 Interfaz moderna y fácil de usar

## Cómo usar

1. Abre el archivo `index.html` en tu navegador web
2. No se requiere instalación ni configuración adicional
3. Los datos se guardan automáticamente en el almacenamiento local del navegador

## Funcionalidades

### Calendario de Horarios
- Visualización semanal de horarios
- Agregar y editar clases por día y hora
- Especificar nombre del curso y salón

### Gestión de Tareas
- Crear nuevas tareas con título, descripción y fecha de entrega
- Asociar tareas a cursos específicos
- Marcar tareas como completadas
- Filtrar tareas por estado (todas, pendientes, completadas)

### Resumen del Día
- Vista rápida de las clases del día actual
- Recordatorios de tareas próximas a vencer

## Tecnologías utilizadas

- HTML5
- CSS3 (con variables CSS y diseño responsive)
- JavaScript (ES6+)
- LocalStorage para persistencia de datos
- Font Awesome para iconos

## Compatibilidad

La aplicación es compatible con los siguientes navegadores:
- Google Chrome (recomendado)
- Mozilla Firefox
- Microsoft Edge
- Safari
